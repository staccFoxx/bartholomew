1. Executive Summary & The Agentic Threat Landscape

The rapid deployment of autonomous AI agents (Claude Code, Cursor Composer, Windsurf Cascade, AutoGen, CrewAI, LangChain) has created an unprecedented attack surface for enterprise organizations. Unlike traditional chat interfaces, agentic systems possess tool-dispatch capabilities: the authority to execute bash commands, query production databases, mutate filesystem trees, and interact with external network services.

Relying on model-level alignment ("system prompt instructions") is fundamentally insecure against indirect prompt injections, jailbreaks, and adversarial context poisoning. Bartholomew establishes the Agentic Runtime Protection (ARP) layer: an in-process, deterministic Abstract Syntax Tree (AST) gate operating strictly before the operating system and database boundary.

THE ZERO-TRUST PRINCIPLE OF AGENTIC EXECUTION

"No autonomous LLM decision may execute at the operating system or data layer without synchronous, compiled invariant validation and cryptographic Non-Human Identity (NHI) proof."

2. Architecture: microsecond-latency In-Process AST Gating
