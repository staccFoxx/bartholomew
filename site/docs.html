Python: protect_agent(agent)

Wrap any autonomous agent (CrewAI, LangChain, AutoGen, or custom) in a single line of code. All agent tools and lifecycle methods are automatically shielded:

from crewai import Agent
from btp_guard import protect_agent

# 1. Instantiate any CrewAI agent
raw_agent = Agent(
    role="Fintech Ops Analyst",
    goal="Query database and execute verified transaction settlements",
    tools=[db_query_tool, bash_runner_tool]
)

# 2. Wrap in 1 line:
agent = protect_agent(raw_agent, spend_cap=50.0, strict=True)

# Gated execution: secrets auto-scrubbed, catastrophic commands blocked in <35µs
result = agent.execute_task("Analyze monthly invoices and query balance")

Enterprise Zero-Code Sidecar Proxy (Docker & K8s)

Intercept outbound agent tool calls and REST endpoints transparently with zero code changes in the agent application. Runs as a high-throughput sidecar container in Kubernetes pods or Docker Compose.

# docker-compose.sidecar.yml
services:
  bartholomew-sidecar:
    image: ghcr.io/ivegotahunnitonit/bartholomew-sidecar:v6.4.4
    ports:
      - "9090:9090"
    environment:
      - PROXY_PORT=9090
      - UPSTREAM_URL=http://agent-app:8000
      - BTP_ALERT_CHANNEL=slack
      - BTP_WEBHOOK_URL=${BTP_WEBHOOK_URL}
    restart: unless-stopped

  agent-app:
    image: your-agent-image:latest
    environment:
      - HTTP_PROXY=http://bartholomew-sidecar:9090
