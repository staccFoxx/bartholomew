# Trinity

**The 1-Click Safety and Runtime Protection Suite for AI Coding Agents**

`[PROTECTED]` | `[ZERO CONFIG]` | `[ZERO DATA LOSS]`

---

## What is Trinity?
Trinity is the all-in-one safety shield for developers using AI coding assistants like Cursor, Claude Code, GitHub Copilot, Windsurf, and VS Code.

When autonomous AI agents write and run code on your computer, Trinity runs quietly in the background to ensure they never delete your data, never leak your API keys, and never execute destructive terminal commands.

---

## Why You Need Trinity
- **Accidental Deletion Defense**: Prevents AI agents from running destructive file deletions, `rm -rf`, or database drops.
- **Secret & API Key Shielding**: Automatically tokenizes and masks API keys, database credentials, and customer PII before sending context to AI models.
- **Fail-Closed Git Protection**: Verifies changes before they touch your Git branch, keeping your codebase intact.
- **Zero Configuration**: Works automatically out of the box with zero complex setup.

---

## How to Use Trinity
1. **Install**: Install the Trinity extension with one click.
2. **Code as Usual**: Open your workspace in VS Code or Cursor. Trinity automatically arms in-process protection.
3. **Monitor Status**: The status bar shows `[PROTECTED]`. Click the Trinity icon in the sidebar anytime to view runtime stats or verify safety tokens.
