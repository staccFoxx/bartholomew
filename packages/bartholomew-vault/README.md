# Bartholomew Vault

**In-Process Data, Credential & MCP Safety Shield for AI Coding Agents**

`[SECURED]` | `[SUB-35US]` | `[HIPAA / SOC 2]`

---

## What is Bartholomew Vault?
Bartholomew Vault is an in-memory security layer that stops sensitive data from ever reaching cloud AI models.

When you use AI coding assistants like Cursor, Claude Code, Windsurf, or Copilot, your code is sent to external cloud servers. Bartholomew Vault automatically intercepts and replaces sensitive API keys, passwords, database URLs, and customer PII with safe surrogate tokens before the prompt leaves your computer.

---

## Why You Need Vault
- **Stop Secret Leaks**: Never accidentally send private API keys or database connection strings to AI models.
- **Protect Customer Data**: Automatically redacts emails, credit cards, SSNs, and healthcare data with HIPAA/SOC 2 compliance.
- **Secure Model Context Protocol (MCP)**: Audits and sanitizes tool parameters used by MCP servers in Claude Desktop, Cursor, and Windsurf.
- **Microsecond-Latency Speed**: Operates in RAM memory with no noticeable latency.

---

## How to Use Vault
1. **Install**: Add the Bartholomew Vault extension to your IDE.
2. **Tokenize Selection**: Select any code or text and click **Tokenize Editor Selection** or use `Ctrl+Shift+P` -> `Vault: Tokenize Selected Text`.
3. **Detokenize on Demand**: Authorized local operations restore original values instantaneously when needed.
4. **Audit MCP Servers**: One click scans and verifies all connected MCP tools and environment configurations.
